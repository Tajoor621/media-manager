# Welcome to Media Manager

Luxury file manager — access to each file of mobile.

## Library
The home screen opens Collections (Photos, Videos, Music, Documents), Recents, and your folders. Everything lives in IndexedDB on this device and works offline.

## Device folder
On Chrome or Edge, open a real disk folder with File System Access. Files stay on disk unless you import them into the Library.

## Viewers
- Images: pinch-zoom, rotate, crop, resize, slideshow
- Video: custom controls, captions (.vtt / .srt), PiP, fullscreen
- Audio: visualizer, queue, lock-screen controls
- PDF, text/code, hex, ZIP, and SQLite

## Share
Use the system share sheet, Nearby (WebRTC room code), or Save to device. This PWA is a share target — send files from other apps.

## Cloud
Google Drive appears when this app is opened from Grok with Drive connected. Dropbox and OneDrive: open their synced folders via Device folder.

## Install
Add to the home screen for fullscreen and offline use. Wrap as an Android APK with PWABuilder / a Trusted Web Activity.

Press ⌘K (Ctrl+K) to search every file.
